# Cyberlife Reborn

A modern backend rebuild of my old Java training project Cyberlife — a cyberpunk android marketplace.

## Why this project

I originally built Cyberlife while learning Java. After several years of backend development experience, I am rebuilding it as a production-like system focused on backend architecture, reliability, testing, and event-driven design.

## Planned architecture

Milestone 1: modular monolith with REST API and database persistence.

Future milestones:
- event-driven order flow
- customer activity timeline
- Kafka/RabbitMQ messaging
- observability
- idempotency
- integration tests

## Tech stack

- Java 21
- Spring Boot 3
- PostgreSQL or MongoDB
- Docker Compose
- JUnit
- OpenAPI
